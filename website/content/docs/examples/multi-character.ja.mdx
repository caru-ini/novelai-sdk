---
title: マルチキャラクター配置
description: キャラごとに別々のプロンプトと位置を指定する。
---

複数のキャラクターを生成する際、それぞれの特徴 (髪色、目の色、服装) が混ざってしまうことがあります。
マルチキャラクター配置機能を使うと、各キャラに別々のプロンプトと位置を指定でき、混ざりを防げます。

```python
from novelai.types import Character, GenerateImageParams

characters = [
    Character(
        prompt="1girl, red hair, blue eyes, school uniform",
        enabled=True,
        position=(0.3, 0.5),  # 左 (X: 0.3, Y: 0.5)、"B3" と同じ
    ),
    Character(
        prompt="1boy, black hair, green eyes, casual clothes",
        enabled=True,
        position=(0.7, 0.5),  # 右 (X: 0.7, Y: 0.5)、"D3" と同じ
    ),
]

params = GenerateImageParams(
    # 全体のプロンプトも指定可能ですが、キャラクターの詳細は上記で指定します
    prompt="two people standing together, holding hands, best quality",
    model="nai-diffusion-4-5-full",
    size=(832, 1216),  # サイズは明示的に指定する必要があります
    characters=characters,
)
```

位置は、いずれかのキャラクターで `position` を指定したときだけ適用されます。
すべてのキャラクターで省略すると、配置は AI に任されます (Web UI の "AI's Choice" と同じ挙動)。
一部のキャラクターだけ指定した場合、未指定のキャラクターは中央に配置されます。

`position` には 0.0〜1.0 の `(x, y)` か、`"A1"`〜`"E5"` の 5x5 グリッドプリセットを指定できます (`"C3"` が中央)。
V4/V4.5 では、Web UI と同様に座標を 5x5 グリッドのセル中心 (0.1, 0.3, 0.5, 0.7, 0.9) にスナップしてから送信します。たとえば `(0.2, 0.5)` は `(0.3, 0.5)` として送られます。
V5 は自由配置に対応しているため、座標をそのまま送信します。
