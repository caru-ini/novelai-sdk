---
title: 多角色定位
description: 为每个角色分配特定的提示词和位置。
---

生成多个角色时，他们的特征 (发色、瞳色、衣服) 有时会混合。
多角色定位允许您为每个角色分配特定的提示词和位置，从而防止此问题。

```python
from novelai.types import Character, GenerateImageParams

characters = [
    Character(
        prompt="1girl, red hair, blue eyes, school uniform",
        enabled=True,
        position=(0.3, 0.5),  # 左 (X: 0.3, Y: 0.5)，等同于 "B3"
    ),
    Character(
        prompt="1boy, black hair, green eyes, casual clothes",
        enabled=True,
        position=(0.7, 0.5),  # 右 (X: 0.7, Y: 0.5)，等同于 "D3"
    ),
]

params = GenerateImageParams(
    # 可以使用通用提示词，但细节应在 characters 列表中
    prompt="two people standing together, holding hands, best quality",
    model="nai-diffusion-4-5-full",
    size=(832, 1216),  # 必须明确指定尺寸
    characters=characters,
)
```

只有当至少一个角色设置了 `position` 时，位置才会生效。
所有角色都省略时，布局交由 AI 决定 (相当于 Web UI 的 "AI's Choice")。
如果只有部分角色设置了位置，其余角色会居中放置。

`position` 接受 0.0–1.0 范围内的 `(x, y)`，或 `"A1"` 到 `"E5"` 的 5x5 网格预设 (`"C3"` 为中心)。
在 V4/V4.5 上，坐标会像 Web UI 一样先吸附到所在 5x5 网格单元的中心 (0.1, 0.3, 0.5, 0.7, 0.9) 再发送，例如 `(0.2, 0.5)` 会作为 `(0.3, 0.5)` 发送。
V5 支持自由定位，坐标按原样发送。
