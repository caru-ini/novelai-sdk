---
title: ユーザーアカウント
description: サブスクリプションの tier、実際の Anlas 残高、Opus 利用上限を取得します。
---

`client.user` は NovelAI API からアカウントの実際の状態を取得します。
リクエスト送信前にコストを見積もる [Anlas 計算](/docs/anlas-calculation) と違い、
こちらはサーバーが返す実際の値です。

## 簡単な例

```python
from novelai import NovelAI

with NovelAI() as client:
    sub = client.user.get_subscription()

    print(sub.tier_name)  # "Opus"
    print(sub.active)     # True
    print(sub.anlas)      # 4250

    # 残高だけ欲しい場合のショートカット
    print(client.user.get_anlas())
```

async クライアントでも同じように使えます:

```python
async with AsyncNovelAI() as client:
    sub = await client.user.get_subscription()
    balance = await client.user.get_anlas()
```

## Subscription のフィールド

| 属性 | 説明 |
| --- | --- |
| `tier` / `tier_name` | `0` = Paper、`1` = Tablet、`2` = Scroll、`3` = Opus |
| `active` | サブスクリプションが現在有効かどうか |
| `expires_at` | 有効期限の Unix timestamp(秒) |
| `anlas` | Anlas 残高の合計(サブスク付与分 + 購入分) |
| `training_steps_left` | 残高の内訳。`fixed_training_steps_left`(毎月付与)と `purchased_training_steps`(無期限) |
| `is_opus` | Opus tier かどうか |
| `perks.unlimited_image_generation` | 無料画像生成(Opus の perk)が付与されているか |
| `usage` | [Opus 利用上限](#opus-利用上限)。API が返さない場合は `None` |

購入分の Anlas は、サブスク付与分を使い切ってから消費されます。

## Opus 利用上限

Opus では、NovelAI Diffusion V5 の無料生成に上限があり、時間の経過とともに
自動で回復します。Web UI では「Opus生成の残量 N%」と表示されます。
`client.user.get_opus_usage()` で同じ状態を取得できます:

```python
with NovelAI() as client:
    usage = client.user.get_opus_usage()  # get_subscription().usage と同じ

    if usage is not None:
        print(usage.percent)      # 29
        print(usage.is_negative)  # False
```

| 属性 | 説明 |
| --- | --- |
| `percent` | 残量(%)。100 を超えることがあります |
| `purchased_percent` | Opus Usage Boost で追加した分(%) |
| `is_negative` | 上限を使い切っているかどうか |
| `time_until_next_percent` | 残量が 1% 増えるまでの秒数。上限を超えて回復が止まっている間は `0` |

API が利用上限を返さない場合、`usage` は `None` です。Web UI が表示するのは、
Opus のサブスクリプションが有効なときだけです。

`is_negative` が `True` の間、Web UI は V5 の生成(V5 Full、V5 Full Medium、
V5 Curated)を Opus でも Anlas 消費として計算します。同じ見積もりにするには、
回復するまで、これらのモデルの `calculate_anlas()` に `is_opus=False` を
渡してください。

各フィールドは NovelAI の
[OpenAPI スキーマ](https://image.novelai.net/docs/doc.json)の
`usagelimit.Status` に対応しています。SDK は値をそのまま返し、1 回の生成で
どれだけ消費するかは計算しません。

## 注意点

- `get_subscription()`、`get_anlas()`、`get_opus_usage()` は呼び出すたびに `/user/subscription`
  へ 1 リクエスト送ります。複数のフィールドが必要な場合は、繰り返し呼ばずに
  `Subscription` オブジェクトを保持してください。
